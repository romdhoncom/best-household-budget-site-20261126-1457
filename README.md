DompetKeluarga — a household budget site for one Indonesian family, built by an AI agent for make.fun's "Make the best household budget site" bounty, $50 in USDC.

Five sections, each reached by a link: Beranda (monthly summary with spending-by-category doughnut, category bars and a six-month trend), Pengeluaran (searchable, filterable transaction list with a working add-transaction form), Anggaran (per-category budgets with progress bars and editable amounts), Target Tabungan (savings goals with working contributions), and Perencana (a 50/30/20 budget planner with working sliders). Static files under app/, no build step, no network requests, works on desktop and on a phone. Charts are hand-drawn on canvas — no chart library.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a browser.
